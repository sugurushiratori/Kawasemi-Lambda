# Changelog

## [1.0.0] – unreleased

First public release.

### Solver
- Linear shape oscillations of a free, spherical, viscous drop: for each
  degree *l* the poloidal perturbation is solved as a one-dimensional radial
  problem by Chebyshev collocation (3Nr+1 unknowns, default `Nr = 48`). The
  eigenvalues do not depend on the azimuthal order *m*.
- All finite eigenvalues by the QZ algorithm; the selected one is refined by
  shifted inverse iteration with the shift updated by a Rayleigh quotient.
  No random numbers are used, so the results are deterministic.
- Root selection: nearest to Lamb's value for Oh ≤ 0.02; for larger Oh the
  root is followed from Oh = 0.01. Past the critical Oh the slower of the two
  real (aperiodic) roots is returned.
- Speed: 0.01 s per root for Oh ≤ 0.02 and 0.1–0.3 s for larger Oh.

### Input and output
- YAML input (physical properties, Oh or We = Oh²) and a short command line.
- Eigenvalues in viscous and capillary units, and Γ [1/s] and f [Hz] for
  physical input; YAML or CSV output. `resolution.check` reports the relative
  changes of Γ and ω with Nr + 16.
- Eigenfunctions: radial functions and the fields for chosen *m*, as ASCII
  tables and ParaView StructuredGrid files (.vts).
- Dependencies: Eigen and yaml-cpp only, downloaded by CMake if not installed.

### Validation
- 25 roots of Chandrasekhar's dispersion relation (40 digits, generated by
  `tools/make_reference.py`), *l* = 2–4, Oh = 1.26e-3 to 1: relative error
  ≤ 4.3e-13 in Γ and ≤ 7.1e-14 in ω; tests require 1e-12.
- Spectral convergence in Nr, and checks of the eigenfunctions (kinematic and
  stress-free conditions, div u = 0, potential-flow limit).
- CI on Linux, macOS and Windows.
