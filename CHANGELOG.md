# Changelog

## [1.0.0] – unreleased

First public release. Derived from the in-house solver *dropEigen* used for
the article (see README).

### Changed from dropEigen
- Name: the program is LAMBDA, the executable `lambdaDrop` (was `dropEigen`).
- The problem is solved for each degree *l* as a one-dimensional radial
  problem (3Nr+1 unknowns) instead of the two-dimensional (r, θ) collocation
  (4·Nr·Nq+Nq unknowns). The eigenvalues do not depend on *m* for a sphere.
- All finite eigenvalues by the QZ algorithm, then refinement by shifted
  inverse iteration with the shift updated by a Rayleigh quotient, instead of
  inverse iteration from a random start vector. Results are deterministic.
- Accuracy: relative error ≤ 4.3e-13 in Γ and ≤ 7.1e-14 in ω for the 25
  validation roots (was ~1e-7 in Γ for Oh ≈ 1e-3, l = 4),
  limited before by the conditioning of the two-dimensional matrices.
- Speed: 0.01 s per root for Oh ≤ 0.02 and 0.1–0.3 s for larger Oh (root
  following); the 25 validation roots take about 4 s in total. dropEigen took
  about 190 s for 18 roots.
- Root selection: for Oh > 0.02 the root is followed from Oh = 0.01, so a
  neighbouring degree is no longer picked up; aperiodic roots past the
  critical Oh are handled (the slower real root is returned).
- Default `Nr` is 48 (was 24).
- Input: YAML file (physical properties or Oh/We), CSV or YAML output with
  Γ [1/s] and f [Hz]. The command line of dropEigen is kept; `m` and `Nq` are
  accepted and ignored. `--all We l [Nr]` now takes the degree *l*.
- Dependencies: Eigen and yaml-cpp only (no BLAS/LAPACK, Boost or OpenMP).
- Eigenfunction output (new): radial functions and the fields for chosen m,
  as ASCII tables and ParaView StructuredGrid files (.vts, binary Float32).
- `resolution.check` reports the relative changes of Γ and ω separately.
- Validation: 25 exact roots (40 digits) of Chandrasekhar's dispersion
  relation, generated by `tools/make_reference.py`; tolerance 1e-12 in λ, Γ
  and ω. A convergence test in Nr and checks of the eigenfunctions.
